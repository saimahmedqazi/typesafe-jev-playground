  <name>Task 1: Implement OpenAI, Anthropic, and Gemini provider execution functions</name>
  <files>src/adapters/providers/openai.ts, src/adapters/providers/anthropic.ts, src/adapters/providers/gemini.ts</files>
  <action>
    1. Create `src/adapters/providers/openai.ts`:
       - Function `executeOpenAI(context, prompt, schema, fetchFn)`:
         - Post to `PROVIDER_ENDPOINTS.openai`.
         - Headers: `Authorization: Bearer ${apiKey}`, `Content-Type: application/json`.
         - Body: `model`, `messages: [{ role: 'system', content: prompt.systemPrompt }, { role: 'user', content: prompt.userPrompt }]`, `response_format: schema`, `temperature: 0`.
         - Parse `choices[0].message.content` as JSON.
         - Extract `usage.prompt_tokens`, `usage.completion_tokens`, `usage.total_tokens`.
         - Return raw result and token usage.
    2. Create `src/adapters/providers/anthropic.ts`:
       - Function `executeAnthropic(context, prompt, tool, fetchFn)`:
         - Post to `PROVIDER_ENDPOINTS.anthropic`.
         - Headers: `x-api-key: ${apiKey}`, `anthropic-version: 2023-06-01`, `Content-Type: application/json`.
         - Body: `model`, `system: prompt.systemPrompt`, `messages: [{ role: 'user', content: prompt.userPrompt }]`, `tools: [tool]`, `tool_choice: { type: 'tool', name: tool.name }`, `max_tokens: 1024`, `temperature: 0`.
         - Find content block with `type === 'tool_use'` and extract `input`.
         - Extract `usage.input_tokens`, `usage.output_tokens`.
         - Return raw result and token usage.
    3. Create `src/adapters/providers/gemini.ts`:
       - Function `executeGemini(context, prompt, schema, fetchFn)`:
         - URL: `${PROVIDER_ENDPOINTS.gemini}/${context.modelConfig.model}:generateContent?key=${apiKey}`.
         - Headers: `Content-Type: application/json`.
         - Body: `systemInstruction: { parts: [{ text: prompt.systemPrompt }] }`, `contents: [{ role: 'user', parts: [{ text: prompt.userPrompt }] }]`, `generationConfig: { responseMimeType: 'application/json', responseSchema: schema, temperature: 0 }`.
         - Parse `candidates[0].content.parts[0].text` as JSON.
         - Extract `usageMetadata.promptTokenCount`, `usageMetadata.candidatesTokenCount`.
         - Return raw result and token usage.
  </action>
  <verify>npx tsx -e "import('./src/adapters/providers/openai.ts'); import('./src/adapters/providers/anthropic.ts'); import('./src/adapters/providers/gemini.ts'); console.log('Provider sub-adapters valid');"</verify>

<task type="auto">
  <name>Task 2: Implement LLMExecutionAdapter with error classification and secret scrubbing</name>
  <files>src/adapters/llm-adapter.ts, src/adapters/index.ts</files>
  <action>
    Create `src/adapters/llm-adapter.ts`:
    1. Implement `class LLMExecutionAdapter implements ExecutionAdapter`:
       - `id = 'llm-practice-adapter'`
       - `name = 'LLM Practice Execution Adapter'`
       - `supportsMode(mode)`: returns `mode === 'llm-practice'`
       - Constructor allows injecting optional `fetchFn` (defaults to global `fetch`) for testability.
       - `execute(context: EvaluationContext): Promise<EvaluationResponse>`:
         - Validate context: check `context.mode === 'llm-practice'`. If not, return error `INVALID_REQUEST`.
         - Check credentials: `context.credentials?.apiKey`. If missing or empty, return error with code `CREDENTIAL_MISSING`.
         - Build prompt via `buildEvaluationPrompt(context.question, context.state)`.
         - Dispatch to `executeOpenAI`, `executeAnthropic`, or `executeGemini` based on `context.modelConfig.provider`.
         - Normalize output: format into `EvaluationResult` (handling boolean value for Noul or numeric value for Score).
         - Calculate `durationMs` and package `EvaluationMetrics`.
         - Error Handling: catch HTTP status codes:
           - 401 / 403 -> `CREDENTIAL_INVALID`
           - 429 -> `RATE_LIMIT_EXCEEDED`
           - 5xx -> `PROVIDER_UNAVAILABLE`
           - Scrub any error messages with regex / `sanitizeSecret` to ensure API keys are never leaked in error text.
    2. Re-export `LLMExecutionAdapter` from `src/adapters/index.ts`.
  </action>
  <verify>npx tsx -e "import('./src/adapters/index.ts'); console.log('LLMExecutionAdapter compiled');"</verify>
  <acceptance_criteria>

    - execute() handles all 3 providers and catches/categorizes errors
  </acceptance_criteria>
  <done>LLMExecutionAdapter implemented</done>
