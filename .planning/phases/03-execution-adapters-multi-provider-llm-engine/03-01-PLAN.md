<task type="auto">
  <name>Task 2: Implement prompt compilation and structured JSON schema engine</name>
  <files>src/adapters/prompt.ts, src/adapters/schemas.ts, src/adapters/index.ts</files>
  <action>
    1. Create `src/adapters/prompt.ts`:
       - Implement `buildEvaluationPrompt(question: AtomicQuestion, state: unknown)`:
         - System Prompt: Establishes JEV evaluator role, defines the semantic boundary of LLM Practice Mode, and requires strict adherence to output schema.
         - User Prompt: Injects serialized JSON state, question details (id, name, description, primitive type), and specific `promptInstruction`.
    2. Create `src/adapters/schemas.ts`:
       - Define standard JEV evaluation schemas for:
         - Noul: `{ value: boolean, confidence: number (0-1), rationale: string }`
         - Score: `{ value: number (0-1), criteria_breakdown?: Record<string, number>, rationale: string }`
       - Implement:
         - `getOpenAISchema(question: AtomicQuestion)` returning OpenAI `response_format` JSON schema.
         - `getAnthropicTool(question: AtomicQuestion)` returning Anthropic tool definition with input schema.
         - `getGeminiSchema(question: AtomicQuestion)` returning Gemini `responseSchema`.
    3. Create `src/adapters/index.ts` re-exporting types, prompt, and schema helpers.
  </action>
