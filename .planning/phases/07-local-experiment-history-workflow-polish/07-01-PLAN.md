<task type="auto">
  <name>Task 1: Implement history storage engine with zero-credential invariant</name>
  <files>src/client/history.ts</files>
  <action>
    Create `src/client/history.ts`:
    1. Define `ExperimentRecord` interface:
       - `id`: string
       - `timestamp`: string
       - `mode`: 'llm-practice' | 'native-jev'
       - `questionId`: string
       - `questionName`: string
       - `questionType`: 'noul' | 'score'
       - `state`: Record<string, unknown>
       - `modelConfig`?: { provider: string; model: string; temperature?: number }
       - `result`: JevResult
       - `metadata`: { durationMs: number; requestId: string; provider?: string; model?: string; tokenUsage?: unknown }
    2. Implement `loadExperimentHistory()`: reads and parses `localStorage.getItem('typesafe_jev_history')`, returns array sorted newest first.
    3. Implement `saveExperimentRecord(record)`:
       - Generates unique ID and ISO timestamp.
       - Prepends to list, caps at 50 records.
       - Runs security check (`assertNoSecretInRecord`): verifies no values match API key patterns (`sk-`, `key-`, `Bearer`, etc.).
       - Saves to localStorage.
    4. Implement `deleteExperimentRecord(id)` and `clearExperimentHistory()`.
  </action>
  <verify>npx tsx -e "import('./src/client/history.ts'); console.log('History module valid');"</verify>
  <acceptance_criteria>
    - loadExperimentHistory and saveExperimentRecord work with localStorage
    - assertNoSecretInRecord enforces zero credentials in stored records
  </acceptance_criteria>
  <done>History storage engine implemented</done>
</task>
