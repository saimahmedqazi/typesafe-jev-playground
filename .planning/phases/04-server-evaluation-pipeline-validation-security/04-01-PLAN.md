<task type="auto">
  <name>Task 1: Define Zod request/response validation schemas and credential extractor</name>
  <files>src/server/validation.ts, src/server/credentials.ts</files>
  <action>
    1. Create `src/server/validation.ts`:
       - `EvaluateRequestBodySchema`:
         - `mode`: `z.enum(['llm-practice', 'native-jev'])`
         - `questionId`: `z.string().min(1, 'Question ID cannot be empty')`
         - `questionType`: `z.enum(['noul', 'score'])`
         - `state`: `z.record(z.unknown()).refine(val => val !== null && typeof val === 'object', 'State must be an object')`
         - `modelConfig`: optional object `{ provider: z.string().min(1), model: z.string().min(1), temperature: z.number().min(0).max(2).optional() }`
       - `validateEvaluationResult(question: AtomicQuestion, result: unknown)`:
         - Validates that `result.type` matches `question.type`.
         - If `noul`: verifies `typeof result.value === 'boolean'`.
         - If `score`: verifies `typeof result.value === 'number'` and `value >= 0 && value <= 1`.
         - Throws `JevEvaluationError(RESULT_VALIDATION_FAILED)` if mismatch.
    2. Create `src/server/credentials.ts`:
       - `extractEphemeralCredentials(headers: IncomingHttpHeaders)`:
         - Parses `x-user-llm-key`, `x-user-llm-provider`, `x-user-llm-endpoint`, `x-user-jev-key`.
         - Strips leading/trailing whitespace.
         - Returns structured `UserCredentials` or undefined.
  </action>
  <verify>npx tsx -e "import('./src/server/validation.ts'); import('./src/server/credentials.ts'); console.log('Validation compiled');"</verify>
  <acceptance_criteria>
    - EvaluateRequestBodySchema rejects missing mode or state
    - validateEvaluationResult enforces boolean for noul and [0,1] number for score
    - extractEphemeralCredentials parses header values
  </acceptance_criteria>
  <done>Zod schemas and credential extractor implemented</done>
</task>

<task type="auto">
  <name>Task 2: Implement evaluate and questions route handlers</name>
  <files>src/server/evaluate.ts, src/server/index.ts</files>
  <action>
    1. Create `src/server/evaluate.ts`:
       - `handleEvaluateRequest(req, res)`:
         - Parse body with `EvaluateRequestBodySchema`. On validation error, return HTTP 400 with `INVALID_REQUEST` code and formatted field errors.
         - Extract ephemeral credentials with `extractEphemeralCredentials(req.headers)`.
         - If mode is `llm-practice` and no `apiKey` is provided, return HTTP 401 with `MISSING_CREDENTIAL`.
         - If mode is `native-jev`, return HTTP 501 `UNSUPPORTED_MODE` (until Phase 5).
         - Dispatch to `llmAdapter.execute(context, credentials)`.
         - Validate result via `validateEvaluationResult(question, response.result)`.
         - Return HTTP 200 with `response` or appropriate error HTTP status.
       - `handleQuestionsListRequest(req, res)`:
         - Return list of registered questions with `id`, `name`, `type`, `description`, `expectedReturnType`, `defaultState`, and presets from `STATE_PRESETS`.
    2. Update `src/server/index.ts`:
       - Mount `POST /api/evaluate` and `GET /api/questions`.
  </action>
  <verify>npx tsx -e "import('./src/server/evaluate.ts'); console.log('Evaluate route compiled');"</verify>
  <acceptance_criteria>
    - /api/evaluate route parses body, executes adapter, and returns typed response
    - /api/questions route returns registered questions and presets
  </acceptance_criteria>
  <done>Evaluation and questions route handlers wired</done>
</task>
