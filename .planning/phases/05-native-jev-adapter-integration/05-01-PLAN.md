<task type="auto">
  <name>Task 1: Implement NativeJevExecutionAdapter with credential routing and secret scrubbing</name>
  <files>src/adapters/native-jev-adapter.ts, src/adapters/index.ts</files>
  <action>
    1. Create `src/adapters/native-jev-adapter.ts`:
       - `export const DEFAULT_NATIVE_JEV_ENDPOINT = 'https://api.jev.ai/v1/evaluate'`
       - `class NativeJevExecutionAdapter implements ExecutionAdapter`:
         - `id = 'native-jev-adapter'`
         - `name = 'Native Jev Execution Adapter'`
         - `supportsMode(mode)`: returns `mode === 'native-jev'`
         - Constructor accepts `{ registry?: IQuestionRegistry; fetchFn?: typeof fetch; endpoint?: string }`.
         - `execute(context, credentials)`:
           - Check mode: if not `native-jev`, return `UNSUPPORTED_MODE`.
           - Extract native Jev API key (`credentials.apiKey` or `credentials.credentials.apiKey`).
           - If missing, return `MISSING_CREDENTIAL` with message: "Missing required Native Jev API key. To execute in Native Jev Mode, provide your Jev API key via x-user-jev-key header, or switch to LLM Practice Mode to practice without a Jev license."
           - Resolve question from registry; if missing, return `UNKNOWN_QUESTION`.
           - Validate state against question; if invalid, return `INVALID_STATE`.
           - Dispatch HTTP POST to Jev endpoint with headers:
             - `Authorization: Bearer ${apiKey}`
             - `x-jev-organization: ${orgId}` (if provided)
             - `Content-Type: application/json`
             - Body: `{ questionId: context.questionId, questionType: context.questionType, state: context.state }`
           - Handle HTTP error codes:
             - 401/403 -> `INVALID_CREDENTIAL`
             - 404 -> `UNKNOWN_QUESTION`
             - 422 -> `INVALID_STATE`
             - 429 -> `RATE_LIMITED`
             - 5xx -> `PROVIDER_ERROR`
           - Scrub any error messages with `.replaceAll(apiKey, '[REDACTED_KEY]')`.
           - Parse response and return typed `EvaluationResponse` with `metadata.mode = 'native-jev'`.
    2. Update `src/adapters/index.ts` to export `NativeJevExecutionAdapter` and `DEFAULT_NATIVE_JEV_ENDPOINT`.
  </action>
  <verify>npx tsx -e "import('./src/adapters/native-jev-adapter.ts'); console.log('Native adapter valid');"</verify>
  <acceptance_criteria>
    - NativeJevExecutionAdapter implements ExecutionAdapter
    - execute() routes only for native-jev mode
    - scrubbed error reporting guarantees zero credential leakage
  </acceptance_criteria>
  <done>NativeJevExecutionAdapter created and exported</done>
</task>
