<task type="auto">
  <name>Task 2: Implement JEV Domain Models and Standardized Error Taxonomy</name>
  <files>src/core/domain.ts, src/core/errors.ts, src/core/index.ts</files>
  <action>
    1. In `src/core/errors.ts`:
       - Define enum / union `EvaluationErrorCode`:
         - `INVALID_REQUEST`
         - `MISSING_CREDENTIAL`
         - `INVALID_CREDENTIAL`
         - `INVALID_STATE`
         - `INVALID_QUESTION`
         - `UNKNOWN_QUESTION`
         - `UNSUPPORTED_MODE`
         - `UNSUPPORTED_PROVIDER`
         - `UNSUPPORTED_MODEL`
         - `PROVIDER_ERROR`
         - `JEV_ERROR`
         - `RATE_LIMITED`
         - `TIMEOUT`
         - `INVALID_MODEL_OUTPUT`
         - `RESULT_VALIDATION_FAILED`
         - `PAYLOAD_TOO_LARGE`
         - `INTERNAL_ERROR`
       - Implement `JevEvaluationError` extending `Error` with `code: EvaluationErrorCode`, `statusCode: number`, `details?: unknown`.
    2. In `src/core/domain.ts`:
       - Define `JsonValue` and `State` (Record<string, unknown> or JsonValue).
       - Define `QuestionPrimitiveType = 'noul' | 'score'`.
       - Define `NoulQuestionDefinition` requiring boolean output.
       - Define `ScoreQuestionDefinition` requiring floating point number [0, 1] output.
       - Define `AtomicQuestion = NoulQuestionDefinition | ScoreQuestionDefinition`.
       - Define `EvaluationContext` containing `mode: ExecutionMode`, `state: State`, `questionId: string`, `questionType: QuestionPrimitiveType`, `modelConfig?: ModelConfig`. (Credentials strictly separate).
       - Define `NoulResult`: `{ type: 'noul', value: boolean }`.
       - Define `ScoreResult`: `{ type: 'score', value: number, range: [0, 1] }`.
       - Define `EvaluationResult` as discriminated union:
         - `{ success: true, result: NoulResult | ScoreResult, metadata: EvaluationMetadata }`
         - `{ success: false, error: { code: EvaluationErrorCode, message: string, details?: unknown } }`
    3. In `src/core/index.ts`:
       - Re-export all types, error codes, and utilities.
  </action>

  </acceptance_criteria>
  <done>Core JEV domain models and error taxonomy implemented with full typing</done>
